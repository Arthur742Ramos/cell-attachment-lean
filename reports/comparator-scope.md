# Comparator scope

Only CellAttachment.two_cell_attachment is a configured theorem hole. There are
no configured definition holes. The exact required toolchain Comparator walks
the theorem's statement dependency graph transitively and compares every ordinary
reachable declaration, including completeStatement, actual adjunction topology,
attaching relation, disk/circle construction and induced maps.

This is deliberate: listing a definition in definition_names would compare only
its type/safety and allow a different body. None of the space, attaching maps or
statement definitions may change body between Challenge and Solution.

Primary current pipeline explanation:
https://github.com/PalomarRegistry/PalomarSubmission/blob/65f0154ed776cd26c224254aa57b379137f28b0d/docs/comparator-declaration-closure.md

The trusted rendering's named declaration view is partial; the entire pinned
Challenge source remains the complete explicit formal statement. The construction
definitions are identical generated source, not submitted solution-only holes.
